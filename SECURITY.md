# Security

The packages here ship text and a small command that lists, prints and
copies it; the command makes no network request and never overwrites a
file. The templates and hooks are shell and Ruby scripts a team copies
into its own repository and CI, so a flaw in one runs with that
repository's permissions.

Report a vulnerability through GitHub's private reporting on this
repository (Security, then Report a vulnerability), not in a public issue.
You will get an answer within a week. A vulnerability in enola, tabula or
taha belongs to that project.
