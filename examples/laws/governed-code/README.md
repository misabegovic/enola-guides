# governed code

The knowledge pages compile into the graph as anchors, and a law demands that
every file of a part has one. The charge service is anchored by the decision
page; the refund service is not, and is named. Without any compiled page the
rule would refuse rather than call everything ungoverned.

Declaration: `enola/constraints/governance.rb`.

Verify it on your own tree: copy `enola/` into the repository, run
`enola constraints lint .`, then `enola --generate . && enola check .`.
